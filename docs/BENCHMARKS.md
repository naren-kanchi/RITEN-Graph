# Benchmarks

Generated by `python scripts/benchmark.py`. Do not edit the numbers by hand.

- Host: Windows-11-10.0.26200-SP0, Python 3.12.10. API runs on the host; databases run in Docker Desktop on the same machine.
- Data version `2811372e1d962fe0`: 7,281 source rows.
- Navigation: 12 sessions of 8 views, 0.35s think time, one client, the same seeded walk per run. 40 training sessions come from a different seed.
- The walk is simulated: 70% of moves follow per-actor habits. Real users may be less predictable, which would lower the prefetch figures.
- These are single-run figures from one laptop. Differences of a few milliseconds are noise.
